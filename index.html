    Источники данных

    Подключения

    API-токены хранятся только на сервере. В браузере секреты не сохраняются.

    Ручной импорт

    Если у сервиса нет API или доступ ещё не настроен

    Выбери источник перед импортом. Приложение распознаёт типовые поля: дата, показы, клики, визиты, расходы, конверсии, охват, реакции, открытия, отписки.

    Импортов в этой сессии пока нет.
    Серверная настройка

    Переменные окружения

    YANDEX_TOKEN
    METRIKA_COUNTER_ID
    WEBMASTER_HOST_ID
    DIRECT_TOKEN
    DIRECT_CLIENT_LOGIN

    Для реального подключения их нужно добавить как Secrets в Cloudflare Worker. После этого кнопка «Обновить данные» запускает синхронизацию.
