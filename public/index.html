    Источники данных

    Подключения

    Здесь видно, какие доступы уже настроены и каких параметров не хватает. Секретные значения приложение никогда не показывает обратно.

    Cloudflare Runtime

    Какие переменные нужны

    Cloudflare → Worker → Settings → Variables and Secrets → Runtime variables and secrets. Пароли, токены и secret-ключи добавляй как Secret; ID сайта и служебные параметры — как обычный Variable.

    ИмяТипЧто указатьЗачем
    Яндекс

    Один токен для Метрики + Вебмастера

    Создай приложение Яндекс OAuth с правами metrika:read и webmaster:hostinfo, получи OAuth-токен и сохрани его как YANDEX_TOKEN. Добавь SITE_URL=https://www.cs-trade.ru/ — приложение попробует само найти нужный счётчик и сайт. ID нужны только как запасной ручной вариант.

    Для Директа нужен отдельный DIRECT_TOKEN и одобренная заявка приложения на доступ к Direct API.

    VK Реклама + UniSender

    Отдельные ключи

    VK Реклама: добавь VK_ADS_CLIENT_ID как Variable и VK_ADS_CLIENT_SECRET как Secret. Worker получает временный access token сам при синхронизации.

    UniSender: включи API-доступ в кабинете и добавь ключ как UNISENDER_API_KEY Secret.

    MAX: создай/используй бота, добавь его администратором канала и укажи MAX_BOT_TOKEN + MAX_CHANNEL_ID.

    Пока без прямого API

    Telegram, Дзен и органический VK

    Для Telegram полная статистика канала идёт через MTProto и авторизацию пользователя-администратора — одного bot token недостаточно. Для Дзена я пока не использую неподтверждённый публичный API, поэтому там остаётся импорт. Органический VK пока импортируется отдельно от VK Рекламы. MAX уже подключается через официальный Bot API.

    Импортов в этой сессии пока нет.
